# Besoin client n°1 : Visualisation sur carte.

## Installer les dependances
python -m pip install -r requirements.txt

## Lancer la visualisation des données
Sans lancer le **script.py**, vous pouvez déjà ouvrir le fichier `carte_arbres.html` pour voir la carte.

```bash
python script.py
```

## Lancer l'interface de classification utilisateur
```bash
python user_interface.py
```
Dans le shell, vous pouvez entrer la spécification de l'arbre pour voir les résultats de classification.
